# Rrjedha – faqja e internetit

Faqe statike (HTML + CSS), pa varësi. Hape `index.html` në shfletues për ta parë.

## Çfarë duhet të ndryshosh
1. `index.html`: kërko `VENDOS_ID_KETU` (ID e Formspree) dhe `DOMENI-YT.com` (emaili yt).
2. Emrin "Rrjedha" nëse zgjedh emër tjetër (kërko në të gjitha skedarët).
3. Çmimet te seksioni `#cmimet`.
